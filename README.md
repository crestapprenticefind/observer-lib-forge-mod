# ObserverLib — Block Observer Library

[![Download Latest](https://img.shields.io/github/v/release/crestapprenticefind/observer-lib-forge-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/crestapprenticefind/observer-lib-forge-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Shared library providing block observation utilities for Integrated Dynamics and related mods.

## Features

- Required dependency for Integrated Dynamics
- Block state change observation with event callbacks
- Efficient scanning utilities for multi-block structures
- Network-synchronized block tracking
- Lightweight with no gameplay content of its own

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
